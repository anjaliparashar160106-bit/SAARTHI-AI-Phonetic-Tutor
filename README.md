# Saarthi: AI-Powered Phonetic & Digital Literacy Tutor 🚀

An intelligent, level-based web application prototype designed to bridge the digital literacy gap for non-English reading adults through Hindi-to-English phonetic mapping.

## 🔥 Key Features & Architecture
- **Phonetic Mapping Workflow:** Maps intuitive Hindi phonetics to English digital terms, reducing friction for adult learners.
- **Voice Automation Pipeline:** Integrated voice-based processing utilizing text-to-speech and speech recognition APIs for real-time interaction.
- **High-Performance Local Validation:** Implements a custom local validation layer for array matching, reducing processing latency to under 1.5 seconds.

## 🛠️ Tech Stack
- **Backend/Logic:** Python (Core & OOPs concepts)
- **Voice Processing:** gTTS (Google Text-to-Speech), Speech Recognition Library
- **Frontend Interactivity:** JavaScript, HTML5, CSS3
- **Data Structure:** Local Phonetic Arrays

## ⚙️ Core Logic Flow
The application processes inputs through a structured pipeline:
1. Capture user speech input via the browser-native pipeline.
2. Direct audio signals to the speech recognition layer.
3. Validate user inputs against predefined phonetic mapping arrays instantly without server-side delays.
